  Movie Rental Performance & Trend Dashboard
  Project Overview

This project analyzes movie rental and sales data to identify trends, patterns, and insights related to movies, genres, ratings, budgets, revenue, and rental performance.

   Tools Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Data Visualization
- Excel Dashboards

   Project Objectives

- Clean and prepare the movie rental dataset
- Analyze movie rental and sales performance
- Identify trends and patterns across genres and ratings
- Analyze movie budgets and revenue
- Create meaningful visualizations
- Build interactive dashboards
- Generate useful business insights
